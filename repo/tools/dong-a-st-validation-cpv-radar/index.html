규정 추적을 밸리데이션의 실제 업무 단계에 대응시켜 봤습니다.

1

프로토콜·보고서 반영

개정된 기준이 밸리데이션 프로토콜(VP)과 결과보고서(VR) 서식에 반영됐는지 먼저 점검합니다.

2

Qualification 4단계 재검토

DQ→IQ→OQ→PQ 각 단계의 판정기준이 최신 규정과 정합한지 확인하고, 필요 시 재적격성평가 대상을 식별합니다.

3

CPV 데이터 기반 갭분석

지속적공정검증(CPV) 데이터로 신구 기준 간 정합성을 4M(Man·Machine·Material·Method) 관점에서 확인합니다.

4

CAPA 이행관리

규정 미반영이 발견되면 CAPA를 등록하고, 재발 방지 조치까지 완료됐는지 실사 전 자체 점검합니다.

신청 2년 3개월 만에 승인, GMP 기준 국제조화의 출발점.

이 도구를 만든 이유

동아ST 대구캠퍼스에 지원하면서, 회사소개 수준을 넘어 "이 공장에서 실제로 무엇을 검증해야 하는가"를 직접 정리해보고 싶었습니다. AI를 활용해 대구캠퍼스의 공개 제품·인증 정보와 국내외 밸리데이션 관련 규정을 함께 리서치하고, 제품·제형별 CQA·CPP 매핑부터 CPV 데이터 분석 방식까지 실제 업무 흐름에 대응시켜 이 시제품으로 직접 설계·개발했습니다. 공개되지 않은 부분은 추정으로 단정하지 않고 명시적으로 남겨뒀습니다. 아직은 공개 정보와 예시 데이터로 구조를 잡아본 v0.1 수준이며, 입사 후에는 실제 밸리데이션 마스터플랜(VMP)·CPV 데이터베이스와 연동해 현장에서 쓰는 도구로 계속 발전시켜보고 싶습니다.

"노하우를 공유한다" — 일하며 얻은 지식을 남겨 다음 사람이 더 빠르게 확인할 수 있도록.
